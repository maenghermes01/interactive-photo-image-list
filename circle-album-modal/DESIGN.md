# Circle Album DESIGN.md

## 제품 톤

Circle Album은 **미니멀 갤러리 + 원형 모션 인터랙션**을 결합한 이미지 탐색 웹사이트다. 화면의 대부분은 조용히 비워두고, 하단의 이미지 카드들이 원형 궤도를 따라 움직이며 콘텐츠를 발견하게 만든다.

## 참고 디자인 방향

- **Apple**: 넓은 여백, 이미지/오브젝트 중심, 절제된 인터페이스
- **Pinterest**: 이미지 발견 경험, 콘텐츠 중심 카드 브라우징
- **Framer**: 모션 중심의 정교한 웹 인터랙션

## 색상

```css
:root {
  --bg: #f5f5f2;
  --text: #1d1d1f;
  --muted: #9a9a94;
  --muted-strong: #6f6f68;
  --card-shadow: rgba(0, 0, 0, 0.12);
  --focus: #0071e3;
}
```

## 타이포그래피

- 기본: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- Hero title: 32~56px, 600 weight, tight line-height
- Hint text: 13~15px, muted gray
- Card metadata: 10~12px, muted gray, 회전 배치

## 레이아웃 원칙

1. 상단과 중앙은 대부분 비운다.
2. 하단 40~50% 영역에 아치형 카드 캐러셀을 배치한다.
3. 카드들은 보이지 않는 원의 윗부분에 놓인다.
4. 중앙 카드가 활성 상태이며 가장 읽기 쉽다.
5. 양끝 카드 일부는 화면 밖으로 잘려 연속성을 만든다.

## 카드 스타일

- 세로형 포스터 비율: 2:3 또는 3:4
- 모서리: 0~8px
- 그림자: 거의 없음 또는 매우 약함
- 이미지 자체의 색감과 그래픽을 강조
- 활성 카드: scale 1.03~1.08, opacity 1, z-index 상위
- 비활성 카드: 약간 작고 기울어진 상태

## 모션 원칙

- 드래그 중 즉각 반응
- 릴리즈 후 가장 가까운 카드로 스냅
- 관성은 과하지 않게
- prefers-reduced-motion에서는 transition 최소화

## 피해야 할 것

- 일반적인 직선형 슬라이더처럼 보이는 것
- 상단에 과도한 내비게이션/버튼을 배치하는 것
- 카드 위에 무거운 오버레이를 얹는 것
- 너무 강한 그림자나 3D 효과로 산만해지는 것
- 모션이 너무 빨라 이미지 감상이 어려운 것
